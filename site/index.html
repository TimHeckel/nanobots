nanobots

Self-improving agent loops for any GitHub repo. An outer loop triages, dispatches, reviews, and learns; nanobot workers claim cards and ship PRs. GitHub is the only state store. When the bots are out of their depth, they summon-human.

curl -fsSL nanobots.sh/install | sh

or npx nanobots-sh init — runs in the repo you want the loop on. No API key needed to install.

what init does

  • Renders the loop into .nanobots/ — prompts, triage rubric, recipes, an append-only learnings log, a one-shot runner.
  • Writes GitHub workflows + issue intake forms; scaffolds the Projects v2 board, Priority/Size fields, labels, and a pinned status issue via gh.
  • Auto-detects your gate commands from package.json; asks ~6 questions; --smart optionally drafts repo-specific recipes with the claude CLI.
  • Then gets out of the way: the repo is fully self-contained — no runtime dependency on nanobots. Your rubric and recipes are supposed to drift from the templates. That drift is the learning.

github actionsinstalled cron workflow — set NANOBOTS_OUTER_ENABLED=1
sandbox cloudsame script + two env vars (Daytona, E2B, …)

Billing is an env var, not a feature: CLAUDE_CODE_OAUTH_TOKEN runs on a Claude subscription; ANTHROPIC_API_KEY is metered; any Anthropic-compatible provider (DeepSeek et al) works via ANTHROPIC_BASE_URL. Mix per runtime — cheap models for workers, a frontier model for the outer loop's judgment.

the parts

outer loop

Never writes product code. Triages every inbox issue against a rubric, writes work specs, dispatches under a WIP cap, reviews and merges PRs, reports each cycle to a pinned issue.

nanobot workers

Anything that reads a work spec and opens a PR with Closes #N. Claude Code shipped; Copilot's coding agent, Codex, or OpenHands plug into the same seam. The board can't tell the difference.

learning

Every finished item appends to LEARNINGS.md; distill passes promote durable lessons into the rubric and recipes. The policy docs are the loop's weights; GitHub history is the training log.

summon-human

Payments, auth, schema, prod infra — hard-gated areas are never auto-worked. The bots post one crisp escalation with options and a recommendation, then wait for you.
